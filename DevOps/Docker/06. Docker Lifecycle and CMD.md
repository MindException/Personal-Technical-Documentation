### 1. 컨테이너 생성 및 시작
```bash
# Run (생성 + 시작)
$docker run [OPTIONS] [IMAGE TAG OR DIGEST] [COMMAND] [ARG]



```

|옵션|설명|
|:---:|:---|
|-d, --detach| 백그라운드 모드로 실행|
|-p, --publish| 호스트 서버와 컨테이너 포트 연결(`[호스트port]:[컨테이너port]`)|
|-v, --voloume| 호스트 파일 및 폴더를 컨테이너에 마운트 (`[호스트 경로 혹은 파일]:[컨테이너 경로 혹은 파일]`) |
|-e, --env|컨테이너 내에서 사용할 환경 변수 설정 |
|--name| 컨테이너 이름 설정|
|--hostname|컨테이너 내부에서 인식하는 hostname 지정|
|--rm| 프로세스 종료 시, 컨테이너 자동 제거|
|-it| 컨테이너 내에 터미널 STDIN 오픈|
|-link|(Legacy) 컨테이너 연결[컨테이너:별칭]|

<br>

```bash
# 예시1 Tomcat
$docker run -d -p 80:8080 --name tc consol/tomcat-7.0

# 예시2 MS SQL
$docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=<password>" -e "MSSQL_PID=Evaluation" -p 1433:1433  --name sql2025 --hostname sql2025 -d mcr.microsoft.com/mssql/server:2025-latest
```

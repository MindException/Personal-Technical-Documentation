## ++추가) 다운스트림 서버에서 파일이 다운로드 되지 않을 경우  

### 1. 필요한 파일 다시 다운로드 시도
```cmd
cd "C:\Program Files\Update Services\Tools"
WsusUtil.exe reset
```
* 종종 하위 스트림 서버에서 싱크는 잘 되지만 업데이트 파일이 다운로드 되지 않는 경우가 있는데, 위 명령어로 다시 시도합니다.   

<br>

### 2. 다운스트림 서버의 기본 게이트웨이를 설정하지 않은 경우

```powershell
C:\Program Files\Update Services\Tools>bitsadmin /list /allusers /verbose
```

* 같은 서브넷 대역이라 게이트웨이를 설정하지 않더라도 BITS 서비스가 게이트웨이가 없으면 네트워크가 없다고 인식합니다.   



## 추가

이거 2개 추가해야 업데이트를 다운로드 혹은 배포가 가능하다.  

```
MIME 형식 추가 창에 다음 정보를 입력합니다:
파일 이름 확장자: .wim
MIME 형식: application/x-ms-wim
MIME 형식을 추가하려면 확인을 선택합니다.
추가를 다시 선택하여 다른 MIME 형식을 추가 한 다음, 다음 정보를 입력합니다.
파일 이름 확장자: .msu
MIME 형식: application/octet-stream
```

## 4. AD WSUS GPO 배포  
_해당 챕터에서는 제일 기본적인 부분만 다룹니다._  

#### 1. 자동 업데이트 구성(1)
![](./MD_Images/20_04001.jpg)
* __경로__: `컴퓨터 구성` -> `정책` -> `관리 템플릿` -> `Windows 구성 요소` -> `Windows 업데이트` -> `자동 업데이트 구성`
* 위 정책을 통하여 Client에서 언제 업데이트 다운로드 및 적용할지 정합니다.  

<br>

#### 2. 자동 업데이트 구성(2)
![](./MD_Images/20_04002.jpg)
* _사내에서 자율적으로 업데이트 하도록하면 일반적으로 업데이트를 잘 하지 않는 경향이 있기 때문에 `4`번 옵션으로 합니다._  
* _사용자가 PC를 사용하지 않는 시간 동안에 다운로드 할 수 있도록 `자동 유지 관리` 중에 설치 옵션도 추가합니다._  

<br>

#### 3. 인트라넷 Microsoft 업데이트 서비스 위치 구성(1)
![](./MD_Images/20_04003.jpg)
* 위 정책을 통하여 Client에서 WSUS 위치를 알 수 있게합니다.  

<br>

#### 4. 인트라넷 Microsoft 업데이트 서비스 위치 구성(2)
![](./MD_Images/20_04004.jpg)
* 위 업데이트 서버와 통계 서버를 다운스트림 서버로 똑같이 설정합니다.  
* _다운스트림 서버가 복제본으로 되어 있어도 컴퓨터 그룹에 정상적으로 추가됩니다._

<br>

#### 5. 인트라넷 Microsoft 업데이트 서비스 위치 구성(3)
![](./MD_Images/20_04005.jpg)
* 위치: Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate
* 위 정책을 적용하게 되면 Client에는 위와 같이 경로가 설정됩니다.  

<br>

#### 6. 컴퓨터 그룹 변경  
![](./MD_Images/20_04006.jpg)
![](./MD_Images/20_04007.jpg)
* 정책으로 설정하지 않을 경우, `할당 되지 않는 컴퓨터`에 Client PC가 등록되게 됩니다.  
* 따라서 위와 같이 그룹을 변경합니다.  

<br>

#### 7. Client PC Update  
![](./MD_Images/20_04008.jpg)  
![](./MD_Images/20_04009.jpg)
* 위 그룹을 변경하게 되면 정상적으로 PC에서 Windows Update가 가능합니다.  

<br>

#### 8. Update 확인  
![](./MD_Images/20_04010.jpg)
* 위와 같이 재부팅 후, 정상적으로 설치 됩니다.

#### ++ 추가) 폐쇄망 환경에서 Windows Update
Windows에서는 WSUS에서 Update 파일 가져올 뿐, 다른 메타 데이터 정보들을 MS 서버로부터 가져오려 합니다.  
이를 생산망과 같은 환경에서 차단하기 위하여 아래와 같은 정책을 추가로 설정합니다.  

#### 1. Windows 업데이트 인터넷 위치에 연결 안 함
![](./MD_Images/20_04011.jpg)
* __경로__: `컴퓨터 구성` -> `정책` -> `관리 템플릿` -> `Windows 구성 요소` -> `Windows 업데이트` -> `Windows 업데이트 인터넷 위치에 연결 안 함`
* 위 정책을 통하여 Microsoft Update 서버와 통신을 차단합니다.  

<br>

#### 2. MS Store 사용 불가
![](./MD_Images/20_04012.jpg)

## 5. 도메인 외부에서 WSUS 구성
_사내에서 사용하는 PC가 도메인에 가입되지 않을 경우에는 아래와 같이 세팅하면 사내 WSUS를 사용 가능합니다._  

![](./MD_Images/20_05001.jpg)
| Name | Type | Data |
|---|---|:---:|
| SetProxyBehaviorForUpdateDetection | REG_DWORD | 0x00000000 (0) |
| TargetGroup | REG_SZ | 컴퓨터 그룹 이름 |
| TargetGroupEnabled | REG_DWORD | 그룹 지정 시 1, 아니면 0 |
| UpdateServiceUrlAlternate | REG_SZ | 공백 |
| WUServer | REG_SZ | WSUS 주소 및 포트 |
| WUStatusServer | REG_SZ | WSUS 주소 및 포트 |
* 위치: Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate

<br>

#### 2. WSUS 사용 옵션 활성화  
![](./MD_Images/20_05002.jpg)
* 위 레지스트리 값을 추가해야 pc가 wsus에서 Update를 가져옵니다.  

#### 3. Client 그룹 지정 허용
![](./MD_Images/20_05003.jpg)

* 위 옵션을 WSUS에서 변경해야 Client PC가 레지스트리에 설정한 그룹으로 자동 가입합니다.

## ++추가) 다운스트림 서버에서 파일이 다운로드 되지 않을 경우  

### 1. 필요한 파일 다시 다운로드 시도
```cmd
cd "C:\Program Files\Update Services\Tools"
WsusUtil.exe reset
```
* 종종 하위 스트림 서버에서 싱크는 잘 되지만 업데이트 파일이 다운로드 되지 않는 경우가 있는데, 위 명령어로 다시 시도합니다.

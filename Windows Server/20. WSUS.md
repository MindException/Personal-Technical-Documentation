## ++추가) 다운스트림 서버에서 파일이 다운로드 되지 않을 경우  

### 1. 필요한 파일 다시 다운로드 시도
```cmd
cd "C:\Program Files\Update Services\Tools"
WsusUtil.exe reset
```
* 종종 하위 스트림 서버에서 싱크는 잘 되지만 업데이트 파일이 다운로드 되지 않는 경우가 있는데, 위 명령어로 다시 시도합니다.   

<br>

### 2. 다운스트림 서버의 기본 게이트웨이를 설정하지 않은 경우

```powershell
C:\Program Files\Update Services\Tools>bitsadmin /list /allusers /verbose

TYPE: DOWNLOAD STATE: TRANSIENT_ERROR OWNER: NT AUTHORITY\NETWORK SERVICE
PRIORITY: HIGH FILES: 0 / 1 BYTES: 0 / UNKNOWN
CREATION TIME: 2026-08-10 오전 10:09:54 MODIFICATION TIME: 2026-08-10 오전 10:09:54
COMPLETION TIME: UNKNOWN ACL FLAGS:
NOTIFY INTERFACE: UNREGISTERED NOTIFICATION FLAGS: 3
RETRY DELAY: 600 NO PROGRESS TIMEOUT: 86400 ERROR COUNT: 0
PROXY USAGE: NO_PROXY PROXY LIST: NULL PROXY BYPASS LIST: NULL
ERROR FILE:    http://WSUSUP22-01:8530/Content/7E/437F192C243E9CF9C87C53D4870EF4B2B582067E.cab -> D:\WSUS-Data\WsusContent\7E\437F192C243E9CF9C87C53D4870EF4B2B582067E.cab
ERROR CODE:    0x80200010 - 현재 활성 네트워크 연결이 없습니다. 어댑터가 연결되면 BITS(Background Intelligent Transfer Service)가 다시 시도합니다.
```

* 같은 서브넷 대역이라 게이트웨이를 설정하지 않더라도 BITS 서비스가 게이트웨이가 없으면 네트워크가 없다고 인식합니다.
